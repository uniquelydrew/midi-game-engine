MIDI Game Engine Privacy Policy

Last updated: 2026-07-31

MIDI Game Engine is designed to work locally on the user's Android device.

Information the app accesses

  • MIDI files selected by the user through Android's system file picker.
  • MIDI input from a connected keyboard while the app is in use.
  • Local playback, layout, library, and diagnostic preferences.

Information the app collects

The app does not send MIDI files, MIDI input, account information, analytics, advertising identifiers, or diagnostic logs to a developer-controlled server. Imported MIDI files remain referenced through Android Storage Access Framework URIs and are not uploaded by the app.

Diagnostics

The optional Export Logs action creates a text file containing local app state, device and Android version information, filenames and URI metadata, and diagnostic events. Export occurs only when the user explicitly requests it and chooses a destination through Android's save picker.

Permissions and sharing

The app does not request broad storage access. Android's system picker grants access only to files the user selects. The app does not sell or share personal information.

Contact

For support, report an issue at GitHub Issues.
