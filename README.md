# MIDI Game Engine (MVP)

## Goal
Turn any MIDI file into a playable game level.

## Architecture
MIDI → SongModel → Chart → Judgment Engine

## Principles
- Single transport clock
- Latency-aware scoring
- Difficulty = multi-dimensional
- Raw data preserved for recalculation

## Next Steps
- Real-time MIDI input
- Transport sync
- Visualization
- Latency calibration UI
